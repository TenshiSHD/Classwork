Software Development Life Cycle Phases

Phase Description
Idea phase Main idea/concept of the of what the product owner will do.
Analysis Phase Analysis Phase: the detailed description of ideas put into code.
Design Phase The design phase: The detailed description design of both idea phase and analysis phase of the product.
Coding Phase The Coding phase: The product owner and team work together and put ideas and design/concept of the product into code and start to produce the product.
Deployment phase The Deployment phase: When the production team finalizes the product they deploy a team of code breakers/fixers to test if the code is correct instead of incorrect.
Maintenance Phase The Maintenance Phase:is when a team of code fixers and breakers come together and work on the code to better fix it and its attributes to make sure the code working in full swing when they finally deploy the product that they have produced.
Retirement Phase The Retirement Phase is when the product owner and product team finally stop committing to the product that they had produced and finally retire.
